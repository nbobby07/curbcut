# Curbcut workspace surface brief

- Scope: replace the primary desktop workspace and its responsive fallback; visitor mode is an active frontend developer repairing one local artifact.
- Audience/job: inspect factual axe evidence, map it to source and rendering, review exact surgical diffs, approve semantic meaning, apply, verify, undo, and export.
- Primary action: scan the current rendered revision; contextual proposals make human approval visually distinct from Apply.
- Proof: source range, highlighted rendered target, axe rule/evidence, proposed result, exact diff, verification state, and agent/human timeline stay synchronized.
- Constraints: three-pane desktop topology; keyboard and screen-reader complete; no chat, dashboard, gradients, neon, excess cards, rasterized controls, backend, or compliance claims.
- Chosen direction: Inspection Ledger — cool white developer-tool chrome, flat ruled surfaces, cobalt focus/action, amber proposal, emerald verification, restrained severity red, system sans plus mono evidence.
- Approved comp: `.impeccable/mocks/decision/inspection-ledger.png`.
- Memorable moment: source line, live target, evidence row, and exact proposal read as one horizontal inspection record before the human authorizes meaning.
- Do not literalize: the comp's invented URLs, issue IDs, file counts, rule versions, or inaccessible color-only statuses; use real Curbcut state and redundant text/icons.
